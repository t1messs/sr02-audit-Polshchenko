# sr02-audit-Polshchenko

Самостійна робота № 2 з дисципліни «Конструювання програмного забезпечення»:
аудит якості та рефакторинг успадкованого коду.

- **Виконав:** Польщенко Нікіта, група 472, варіант № 13 (TaxiDispatch).
- **Джерело коду:** А — пакет викладача `V13-TaxiDispatch`
  (репозиторій курсу `andreichenko256/legacy-code`), скопійований без змін у коміт `baseline`.
- **Модуль-донор:** `Dispatcher.Assign` — призначення водія на замовлення.
- **Профільний дефект:** довгий метод із мертвим кодом і закоментованими гілками;
  обов'язкові рефакторинги — Remove Dead Code, Extract Method.

## Структура

| Шлях | Що це |
|---|---|
| `src/` | код, що аудитується (.NET 8, `RollForward Major` — запускається й на новіших .NET) |
| `Legacy.Tests/` | характеризаційні тести (xUnit) |
| `docs/` | метрики, реєстр дефектів, план, журнал рішень, реєстр боргу, виводи сценарію |
| `tools/` | налаштування для вимірювання цикломатичної складності інструментом CA1502 |

## Теги

- `baseline` — вихідний код до аудиту;
- `safety-net` — готова сітка характеризаційних тестів;
- `after-refactoring` — усі рефакторинги виконано.

## Як запустити

```bash
dotnet build
dotnet run --project src
dotnet test
```

Цикломатична складність методів за інструментом (CA1502, поріг 1):

```bash
bash tools/measure-cc.sh
```
Скрипт тимчасово підключає налаштування з `tools/`, збирає `src/` і прибирає за собою;
код проєкту не змінюється.
